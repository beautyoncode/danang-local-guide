# 🌴 Đà Nẵng Local Guide

🇬🇧 *English: xem "Da Nang Local Guide (EN)"*

> **Ăn gì, uống gì, đi đâu ở Đà Nẵng, do người Đà Nẵng chọn, sắp xếp theo cách bạn thật sự quyết định hôm nay làm gì.**
> Trả lời trong 30 giây: *Làm gì? Ở đâu? Lúc nào? Đi với ai?*

---

## 🔥 Bắt đầu từ đây

- **Lần đầu đến Đà Nẵng** → mở *Experiences* và chọn một khung giờ
- **Chỉ có 1 ngày** → chọn một khung giờ bên dưới và đi theo một trải nghiệm có sẵn
- **Đang sống ở đây / ở dài ngày** → xem *Neighborhoods*
- **Cần chỗ làm việc** → *Places* → Type = Coffee → Vibe = Work-friendly

*(Trong Notion: biến từng dòng trên thành liên kết tới trang hoặc view tương ứng. Xem Build Guide, Bước 7.)*

---

## 🍜 Bạn muốn làm gì?

| Mình muốn... | Đi tới |
| --- | --- |
| 🍜 Ăn | Places → Type = Food · Đồ ăn |

| 🌊 Biển / nước | Places → Type = Outdoor · Ngoài trời, hoặc Category = Beach |

| 🥾 Leo núi / thiên nhiên | Places → Category = Hike · Leo núi |
| 🍻 Đi bar / pub | Places → Type = Nightlife · Bar/Pub |
| 💆 Thư giãn | Places → Type = Wellness · Spa & Massage |
| 💻 Làm việc | Places → Vibe = Work-friendly · Làm việc tốt |

## 🧭 Trải nghiệm có sẵn

- 🌅 Sáng Đà Nẵng bản địa: đi dạo phố + bún chả + cafe muối
- 🏄 Chèo SUP + mỳ tôm mực buổi sáng ở Mân Thái
- 🌇 Hoàng hôn sông Hàn → bánh canh → đi dạo đêm
- 🏔️ Nửa ngày Sơn Trà
- 🏮 Nửa ngày Hội An

*(Trong Notion: thay bằng linked view của Experiences, dạng gallery.)*

---

## 🔎 Cách chúng mình giới thiệu

Mỗi địa điểm có một ghi chú ngắn **Why we go (VI)**. Xem **How We Recommend (VI)** để biết cách chúng mình chọn. Mỗi địa điểm có ngày **Last checked** để bạn biết lần kiểm tra gần nhất.
